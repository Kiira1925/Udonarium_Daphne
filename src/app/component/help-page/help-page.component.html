このタブ:

コマの選択と行動

複数のコマを選ぶと、移動やバフ付与などをまとめて操作できます。

Ctrl + 左クリック
クリックしたコマの選択と選択解除を切り替えます。選択中のコマには、名前の上に矢印アイコンが表示されます。
Shift + 左ドラッグ
PCでは、テーブルの空き部分をドラッグして矩形内のオブジェクトをまとめて選択します。
長押ししてからドラッグ
タッチ操作では、テーブルの空き部分を長押しし、選択表示が出てからドラッグします。
選択中コマへの付与
バフ・デバフは選択中のコマへ付与されます。何も選択していない場合は、チャットの送信元または効果管理の「使用コマ」が対象になります。
行動完了
ラウンド1以上の間は、キャラクターのチャットパレットまたはキャラコマの右クリックメニューから切り替えられます。未行動はグレー、完了済みはチェックで表示され、完了時はメインチャットへ記録されます。
lightbulb
選択をすべて解除するテーブルの空き部分を短くクリックします。

キャラクターとZIP

キャラコマの情報は右クリックから編集し、ZIPファイルで持ち運べます。

キャラクターの詳細
キャラコマを右クリックして「詳細を表示」を選びます。画像、ステータス、チャットパレットなどを編集できます。
そのキャラの効果管理
キャラコマを右クリックし、チャットパレット表示の下にある「効果管理を開く」を選ぶと、そのキャラを「使用コマ」にした状態で開きます。
ZIPを読み込む
保存済みのZIPファイルをブラウザ画面へドロップします。GMモード中に追加したキャラも、詳細やチャットパレットを通常どおり開けます。
キャラコマをZIP保存する
キャラコマを右クリックし、「詳細を表示」→「保存」を選びます。画像、ステータス、チャットパレットは保存されます。付与中の効果と、効果管理画面で作成したテンプレートは保存されません。
inventory_2
テンプレートも持ち運ぶには 効果管理の「全テンプレートをコピー」で得た定義行をチャットパレットへ登録してからZIP保存します。キャラZIP読込時に /buff 効果名/効果/ラウンド 形式の行から自動登録され、/buff テンプレート名 のような呼び出し行だけでは登録されません。

コピー形式では、テンプレート名・ステータス名・自由記述に半角 / を使用できません。自由記述の半角 ; も複数効果の区切りとして扱われます。

マップマスクのスクラッチ

マスク全体を外さず、クリックやドラッグで選んだ任意のマスを公開したり、公開箇所を元に戻したりできます。

  1. 編集を始める マップマスクを右クリックし、「スクラッチで一部公開」を選びます。編集者の画面だけでマスクが薄くなり、下のマップを確認できます。各マスの緑の目アイコンは公開済み、赤の目に斜線のアイコンは未公開を示します。
  2. 公開するマスを選ぶ 未公開のマスをクリックするか、ドラッグでなぞって複数選択します。公開済みのマスは選択されません。離れたマスも続けて追加でき、選択済みのマスをクリックまたはドラッグすると選択を解除できます。
  3. 公開を確定する 「選択した○マスを公開」を押すかEnterキーを押すと、選択したマスが透明になり全参加者へ同期されます。確定前は、他の参加者から下のマップは見えません。
  4. 公開箇所を元に戻す 右クリックメニューの「スクラッチした箇所を元に戻す」、または編集ツールバーの「編集モード」を「元に戻す」へ切り替え、公開済みのマスをクリックまたはドラッグで選んで確定します。未公開のマスは選択されません。チェックが付いた側が現在のモードで、モードを切り替えると選択中のマスはクリアされます。
lock
同時操作を防止します編集中のマスクはロックされ、他の参加者は移動・設定変更・削除・別のスクラッチ操作を行えません。編集者が切断した場合は自動で解除されます。

Esc または「キャンセル」で、公開せずに編集を終了できます。

接続と同期

オレンジ色の sync! が続く
表示にマウスを置いて対象参加者を確認し、「メニュー → 接続」でその参加者のHealthとPingを確認します。一時的な表示は通常の同期処理です。
ローカル環境を一時公開する
公開用バッチを起動し、ターミナルに表示される PUBLIC URL（https://*.trycloudflare.com/）を参加者へ共有します。
warning_amber
一時公開URLは毎回変わりますURLを知っている人はアクセスできます。セッション終了後は公開用バッチを停止し、再起動時は新しいURLだけを共有してください。
送信元を先に確認

メインチャットでは、入力欄の送信元にキャラコマを選びます。ステータス参照とリソース操作は送信元、バフの付与先は選択中のコマです。

キャラクターのチャットパレットでは、そのキャラを含む複数のコマを選択していると、選択中の各キャラを送信元にして同じ行を1回ずつ実行します。意図しないコスト消費を避けるには、送信元にする1体だけを選択してください。

このタブ:

ステータス参照

ステータス名を { } で囲むと、送信元キャラの現在値を判定へ組み込めます。バフ・デバフによる補正も反映されます。

書式 2d6+{ステータス名}
実行例
前提
送信元キャラの筋力が3
入力
2d6+{筋力}
結果
2d6+3 として判定

リソース操作

コマンドは半角の : で始めます。値には数値、BCDice、四則演算、{ステータス名} 参照を使用できます。

リソース操作コマンドの書式
書式動作
:HP+値現在値へ加算します。
:HP-値現在値から減算します。
:HP*値 / :HP/値現在値を乗算または除算します。0による除算は実行されません。
:HP=値現在値を指定値にします。
:HP-4 :MP-4半角スペースで区切り、行頭から連続する複数の操作を実行します。
:HP-4 コメント最初のコメント以降は表示だけを残し、コマンドとして実行しません。
M式の末尾へ付け、処理後の値をリソースの最大値以下にします。
!式の末尾へ付け、計算結果が指定した増減方向と逆向きになる場合は操作量を0にします。
! を使うダメージ計算
前提
HP 20、防護 6
入力
:HP-4+{防護}!
結果
回復へ逆転させず、HPは20のまま
  • :HP-1d6HPからBCDiceの結果を減らします。
  • :HP-10+5-10+5 を計算し、HPを5減らします。
  • :HP+30MHPを30回復し、最大値で止めます。
  • :HP-4 :MP-2 【攻撃コスト】HPとMPを操作し、後半をコメントとして残します。

式内の空括弧 () は0として扱われるため、チャットパレットの入力欄用の雛形にも使えます。未登録の補正ステータスを参照すると、詳細の「バフ・デバフ」欄へ値0で自動追加されます。

戦闘の進行と一時効果

「メニュー → 効果」から、ラウンド、行動完了、バフ・デバフ、キャラごとのテンプレートをまとめて管理できます。

このタブ:

ラウンド管理

GMモード中に「メニュー → 効果」を開き、Next Round で進行、Reset で戦闘を終了します。

ラウンド操作コマンド
書式動作
/round +1ラウンドを1進めます。メインチャットへ 【1ラウンド目】 のように記録し、効果の残りラウンドを減らします。
/round resetラウンドを0へ戻し、付与中の効果と行動完了状態を削除します。
  • ラウンド1以上では、各チャットへ 1R のような注釈が付きます。
  • 効果管理には、テーブル上コマの行動完了数が 2/3 のように表示されます。
  • 全キャラが行動完了になるまで、次のラウンドへ進めません。進行後は行動完了がリセットされます。
restart_alt
Resetは取り消せません付与中の効果と行動完了状態を即時に削除します。戦闘終了時にだけ実行してください。

バフ・デバフ

/buff の各要素は半角 /、複数効果は半角 ; で区切ります。効果時間は1以上で指定し、小数は切り捨てられます。

バフ・デバフコマンドの書式
書式動作
/buff 効果名/対象+数値/ラウンド対象ステータスへ加算する効果を付与します。- は減算、* は乗算です。
/buff 効果名/自由記述/ラウンドステータスを変えず、説明文だけの効果を付与します。
/buff 効果名/効果1;効果2/ラウンド1つのバフへ複数の補正や説明をまとめます。
/buff テンプレート名送信元キャラに登録済みのテンプレートを付与します。
/buff テンプレート名 :MP-3付与と同時に、送信元キャラのリソースを操作します。リソース操作は行末へ連続して置きます。
複数の補正をまとめる
入力
/buff 戦闘態勢/筋力+2;防護+1;移動力-1/3
結果
3つの補正を「戦闘態勢」として3ラウンド付与
  • /buff 有利/次の判定に有利/1自由記述の効果を1ラウンド付与します。
  • /buff キャッツアイ :MP-3テンプレートを付与し、送信元キャラのMPを3減らします。
  • /buff 魔法支援/命中+1/3 :MP-5 :魔晶石5点-1効果付与と複数のコスト消費を同時に処理します。
refresh
同じ効果をもう一度付与した場合同じ対象・名前・内容の行は増えず、指定した残りラウンドへ更新されます。同じ残り時間なら効果は変わりませんが、末尾やテンプレート内のリソース操作は毎回実行されます。MPなどの二重消費に注意してください。

補正先ステータスが存在しない場合は、詳細の「バフ・デバフ」欄へ値0で自動追加されます。補正値と補正後の値も同じ欄で確認できます。

効果管理画面

テンプレートには複数のステータス補正・自由記述・リソース操作を登録できます。

使用コマ テンプレートの所有者で、付与時のリソース消費元です。
付与対象 テーブルで選択中のコマです。未選択時は使用コマになります。
  1. 使用コマを選ぶそのキャラに登録されたテンプレートが表示されます。
  2. 必要なら対象コマを選ぶ複数選択すると、まとめて付与できます。
  3. テンプレートの再生ボタンを押す効果と登録済みのリソース操作を同時に実行します。
content_copy
テンプレートをZIPで持ち運ぶ「全テンプレートをコピー」で複数行の定義コマンドを取得し、チャットパレットへ貼り付けてからキャラZIPを保存します。半角 / は項目、半角 ; は複数効果の区切りなので、名前や自由記述には使わないでください。
表示モードとして使います

GMモードとステータス秘匿は、セッション中の表示を整理する機能です。参加者のアクセス権限を制御する機能ではありません。

このタブ:

GMモード

切り替える
「メニュー → 接続」から、自分のGMモードを有効または無効にします。ルーム作成者や接続状態には依存しません。
GM向け表示
秘匿中のステータスと、秘匿されたリソース操作ログの詳細を確認できます。
キャラクターを閲覧する
GMモード中に作成したキャラやZIPから追加したキャラも、詳細やチャットパレットを通常どおり開けます。
再接続する
GMモードはブラウザごとのローカル設定です。再接続後は必要に応じて「メニュー → 接続」で状態を確認してください。
privacy_tip
GMモードは権限制御ではありません各参加者が自分で切り替えられます。画面共有や配信中に有効化する場合は、秘匿情報の映り込みに注意してください。
