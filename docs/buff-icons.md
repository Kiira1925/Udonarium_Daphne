# 汎用バフアイコン素材

バフ／デバフや自由記述の効果に割り当てるための個別PNG素材です。同じ分類に複数の候補を用意し、見た目を選べる構成にしています。アイコンの選択・表示機能はまだ実装していません。

- 保存先: `src/assets/images/buff-icons/`
- 一覧: `http://127.0.0.1:4200/assets/images/buff-icons/preview.html`
- 解像度: 1254×1254px（全16種類共通）
- 形式: PNG（背景を含む不透明な正方形、文字や数値なし）
- 生成方法: 組み込み `image_gen`。画像ごとに個別生成。
- 生成プロンプト: [buff-icons-prompts.json](buff-icons-prompts.json)
- 素材一覧: [index.json](../src/assets/images/buff-icons/index.json)

## 分類と候補

| 分類 | 候補数 | 表現 |
| --- | ---: | --- |
| ステータス上昇 | 4 | 矢印・成長・活性・高揚 |
| ステータス低下 | 4 | 矢印・減衰・弱化・消耗 |
| 持続効果 | 2 | 循環・波紋 |
| 保護 | 2 | 包囲・重層 |
| 行動阻害 | 2 | 拘束・封鎖 |
| 特殊効果 | 2 | 星・軌道 |

分類は選択時の目安として扱います。画像自体に特定のステータス名や効果を固定しません。

## デザイン方針

太い黒線、鮮やかな背景、平面的な塗り、手描きの輪郭を共通にした独自デザインです。参考画像からは描き方の大まかな方向性を読み取り、画像のコピー、トレース、直接的な図案・構図の流用は行っていません。元の参考画像はプロジェクトに含めていません。

上昇と低下は、方向を示す矢印・段差・活性と亀裂・姿勢の変化で表現し、色と形の両方で区別します。一覧ページには32px・48pxの表示例と背景の明暗切り替えがあります。

## 用途の具体例

<small>攻撃上昇・防御上昇・命中上昇はいずれも「ステータス上昇」、攻撃低下・防御低下はいずれも「ステータス低下」から自由に選びます。持続効果は再生・継続ダメージなど、保護は耐性・軽減・無効化などへ割り当てられます。</small>
